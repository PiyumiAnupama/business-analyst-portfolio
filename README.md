## About This Portfolio

Each project folder contains a full Business Requirements Document, stakeholder 
analysis, and supporting artifacts (gap analysis, diagrams, SQL queries, or 
cost-benefit models, depending on the project's focus). Every case study is 
self directed, built to reflect realistic business scenarios across different 
industries, with a consistent documentation standard across all three.

See each project's own README for a summary, or open the full `.docx` inside 
each folder for the complete write up.
