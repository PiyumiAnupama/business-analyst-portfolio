# Loan Application Processing System

**Domain:** Banking / FinTech | **Type:** Business Analyst Case Study

## Overview
Manual loan processing was causing 7–14 day approval delays and high application 
abandonment. This case study analyzes the process end-to-end and proposes an 
automated solution reducing projected processing time to 1–3 days while 
maintaining full compliance traceability.

## Key Artifacts
- Stakeholder Analysis 
- Business Requirements Document
- As-Is/To-Be Gap Analysis 
- User Stories & Acceptance Criteria

## Skills Demonstrated
Stakeholder analysis, compliance-aware requirements engineering, business process 
gap analysis, user story writing, cross-functional conflict navigation.
