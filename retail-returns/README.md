# E-commerce Returns & Refunds Optimization

**Domain:** Retail / E-commerce | **Type:** Business Analyst Case Study

## Overview
A 22% return rate was eroding margins, with three competing, unconfirmed theories 
about the cause aggressive discounting, packaging damage, and category/supplier 
quality. Rather than accepting any theory at face value, this case study uses 
SQL to test each hypothesis directly against order and return data, backed by a 
cost-benefit case projecting a net annual benefit of LKR 47.5M.

## Key Artifacts
- Stakeholder Analysis
- Data Requirements & SQL Queries 
- Cost-Benefit Analysis
- As-Is/To-Be Gap Analysis
- Business Requirements Document (BRD)
- KPI Dashboard Visual
- User Stories & Acceptance Criteria

## Skills Demonstrated
SQL based hypothesis testing, data requirements definition, cost benefit analysis, 
KPI design directly traceable to data findings, stakeholder bias awareness, gap 
analysis, BRD authorship.
